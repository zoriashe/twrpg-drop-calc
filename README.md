# TWRPG — калькулятор дропа

Две статические страницы, собранные по результатам разбора скрипта карты TWRPG (`war3map.j`).

| Страница | Что делает |
|---|---|
| [`index.html`](index.html) | Интерактивный калькулятор шанса дропа с боссов групп `gr`, `Gr`, `hr`, `Hr`, `jr`, `Jr` |
| [`guide.html`](guide.html) | Как работает система дропа: формулы по шагам и полные таблицы по 42 боссам |

## Калькулятор

Повторяет логику функции `N2i` из скрипта карты — те же множители, в том же порядке, с теми же обрезками:

1. **Дроп-рейт монстра** — размер группы и сложность, слагаемые перемножаются, итог зажимается в `[-100 %, +650 %]`
2. **Множитель сакрифайсов** — `+0.8` за каждого, кто пожертвовал лично вам; жертвы «всем» делятся на число нежертвующих; недобор до минимума группы компенсируется; потолок `×3.0`
3. **Штраф за отсутствие виша** — `×1.15 ÷ количество обычных строк` на боссах рангов 4–5
4. **Виш на боссах ранга 3** — `×2.5` загаданному предмету
5. **Иконка** — `×1.5` предметам подходящей категории и редкости

Что учитывается: босс, число игроков, сложность (Normal / Hard / Practice), виш, сакрифайсы четырёх видов и активная иконка. По клику на любую строку лута открывается пошаговый разбор — откуда взялось итоговое число.

## Данные

- Дроп-таблицы, шансы, группы масштабирования и флаги боссов извлечены из `war3map.j` статическим разбором
- Названия предметов — из выгрузки объектов карты; категории и подтипы — из таблиц `Y[]` и `xv[]` скрипта (`war3map.j:2301`), тех же, из которых собирается тултип в игре
- Редкость берётся из скрипта: именно её проверяет код при расчёте бонуса иконки, и у части материалов она не совпадает с цветом подсветки в игре

Сам файл карты в репозиторий не входит.

## Локальный запуск

Зависимостей нет — обе страницы самодостаточны. Достаточно открыть `index.html` в браузере или поднять любой статический сервер:

```sh
python -m http.server 8000
```
